# Hands kit: the asset contract (D-114)

Hands as presenters: a hand points at a diagram, carries an object in and leaves it, counts on its fingers.
The runtime (`runtime/hands.js`, `Loom.hands`) only STAGES hand art; code may not draw figurative content
(D-102). This folder holds the art, one folder per family.

```
assets/hands/
  README.md              this contract
  placeholder/           the built-in stand-in set (abstract, labelled PLACEHOLDER, CC0, generated)
  <family>/<pose>.svg    designed art, one file per pose
  <family>/<pose>.json   optional sidecar: overrides the data attributes below
  <family>/LICENSE.txt   the licence text, and who made it
```

## Families

One family per look family, named by its register. The runtime picks a pack's `hands.family` if the pack declares
it, else by `look_family`:

| look_family | default family | drawing |
|---|---|---|
| illustrated | `cartoon` | flat colour, soft ink outline, rounded fingers, 4 fingers allowed |
| editorial | `flat` | flat colour, no outline, realistic proportions, 5 fingers |
| technical | `line` | single-weight line art, no fill except the sleeve, 5 fingers |

A scene may ask for any family by name (`family: "cartoon"`).

## Poses (file names)

`point`, `hold`, `pinch`, `place`, `open`, `tap`, `grab`, `thumbs`, `count1`, `count2`, `count3`, `count4`,
`count5`. A family must ship all thirteen; a missing pose is an error at runtime (`hands_pose_missing`) and falls
back to `open`.

| pose | what it shows | anchor |
|---|---|---|
| point | index finger extended, others curled | tip of the index finger |
| tap | index finger slightly bent, about to touch a screen | tip of the index finger |
| pinch | thumb and index meeting (holding a small thing) | the pinch point |
| hold | palm up, cupped, carrying an object | centre of the carried object |
| place | palm forward, fingers out, setting an object down | centre of the carried object |
| grab | fist closed around a handle or bar | centre of the grip |
| open | open palm facing the viewer, fingers together | palm centre |
| thumbs | thumb up, fist | palm centre |
| count1..5 | that many fingers raised | palm centre |

## Geometry

- **Canonical orientation: the hand enters from the BOTTOM.** Fingers point up, the forearm and sleeve run down
  to the bottom edge of the viewBox. The runtime rotates the art for the other edges (left, right, top).
- **viewBox:** `0 0 400 640` recommended (any size works; keep every pose of a family the same size so pose swaps
  do not jump).
- **Wrist edge:** the sleeve must reach the bottom edge of the viewBox, straight and square, centred on
  `data-wrist`. The runtime continues it past the frame edge with a plain band `data-wrist-width` wide in the
  sleeve colour, so a hand never floats.
- **Anchor:** the point the scene aims (see the table), in viewBox units.

Root `<svg>` attributes (or the same keys in the JSON sidecar):

| attribute | example | meaning |
|---|---|---|
| `data-anchor` | `"200 52"` | anchor point, x y in viewBox units |
| `data-wrist` | `"200 640"` | centre of the wrist edge, on the bottom edge |
| `data-wrist-width` | `"150"` | sleeve width at the wrist edge |
| `data-licence` | `"CC0-1.0"` | `CC0-1.0`, `MIT`, or `in-house` (designed for Loom, rights held) |
| `data-author` | `"..."` | who made it |
| `data-placeholder` | `"true"` | only on the placeholder set |

## Colour: classes the runtime recolours

No colour in the art is final: every filled shape carries one of these classes and the runtime sets its fill from
the style pack (skin tones from `characters.skin`, sleeve from `characters.cloth` or a token the scene names).

| class | fill from |
|---|---|
| `hand-skin` | `characters.skin[i]` (the scene's `skin` index) |
| `hand-skin-shade` | that skin, 12% darker |
| `hand-nail` | that skin, 30% lighter |
| `hand-sleeve` | the sleeve token (default `characters.cloth`, else `accent`) |
| `hand-sleeve-shade` | the sleeve, 14% darker |
| `hand-line` | stroke from `characters.ink` or `ink` (outlines; use `fill="none"`) |
| `hand-label` | `ink` (placeholder only) |

Draw the art with any neutral hexes; they are replaced. No gradients, no filters, no embedded images, no text
(except the placeholder's label), no ids that would collide (the runtime prefixes ids anyway).

## Size and weight

Under 20 KB per pose; under 300 nodes. Paths merged where they share a class.

## Licence

CC0 or MIT from a verified source, or designed in-house for Loom. Put the licence text in the family's
`LICENSE.txt`. No download without Kshitij's approval (Video-Engine rule 11).

## The placeholder set

`placeholder/` is deliberately abstract (a mitten or a rounded block for the palm, capsules for fingers, a dashed
outline, a cross at the anchor, the word PLACEHOLDER and the pose name). It proves the staging, not the look. It is
generated by `python3 tests/suites/primitives_material_footage_hands.py --make-hands`, and the runtime carries a copy as its fallback
(`--sync-hands`; a test keeps them equal). Every time it is drawn the runtime raises `Loom.warn("hands_placeholder")`,
so it can never reach a real render unnoticed. The art prompt is in `docs/ASSET_WISHLIST.md`, "Hands kit (D-114)".
