# Review: Maya v3 "final" from Claude Design (2026-10-02)

STATUS: REVIEWED 2026-10-02.

**Verdict:** this is usable. Of the nine v2 fixes, five landed, three improved part way, and one was not done:
the props are unchanged. The props no longer need a round trip, because the delivery now declares which slot each
of its colours means, and intake can map them (`--declared-slots`, below). What is left is small drawing polish
plus two pose fixes. They can go back as same-name files while the rig importer is built.

**Input:** `Maya character design library final.zip`, from Kshitij's `Documents/Characters` folder.
- Batch `maya_story_parts_v4`; the page is titled "model sheet v3".
- 203 parts: 171 carried over from v2, 77 of them redrawn, plus 32 new.
- No props were redrawn.

**How it was judged (all by tooling, from the delivered files):**
- `py tools/asset_intake.py <zip> --batch maya-v3` → `assets/incoming/maya-v3/INTAKE.md`. 203 assets, 3 fail
  (the props).
- **This delivery has a new shape:** there are no engine scripts. The review page (`delivery/index.html`, kept
  in `assets/incoming/maya-v3/_page/`) carries every build as data:
  - `<script id="loom-builds">` has 97 builds, each a list of (part, transform);
  - three more figures are baked into the page (stand, point, sit).
- `tools/rig_review.py` now reads that shape (D-89):
  - it rebuilds all 100 builds from the DELIVERED part files, using the page's transforms verbatim and the page's
    own captions;
  - result: 0 missing parts, and 0 unread parts in the baked figures;
  - `--zoom` makes close-ups.
- What changed since v2 was found by hashing every part file with its metadata stripped.
- Sheets: `docs/assets/reviews/maya-v3/` (`builds_00` to `builds_05`, `closeup_*`, `expressions.jpg`, `hands.jpg`,
  `turnaround.jpg`, `expression_distance.json`).
