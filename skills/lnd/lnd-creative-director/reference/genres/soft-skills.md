# Genre: soft-skills

**Grounding posture:** faithful (models and frameworks from the source/knowledge sheet; scenarios may be invented if framed).
**Arc:** the moment it goes wrong* -> the model* -> the model applied (worked)* -> your turn (practice)* -> payoff*
**Opens with:** a short, recognisable interaction that goes slightly wrong (framed as invented).
**Good:** two characters, the same moment replayed done well; the model as 3-4 named moves; a pause-and-predict on the tempting wrong move.
**Bad:** a list of tips; perfect characters; lecturing.
**Never:** stereotypes; blaming the viewer; invented research.
**Visual kinds that fit:** dialogue scenes, replay with the change highlighted, a character's thoughts, a short checklist.
