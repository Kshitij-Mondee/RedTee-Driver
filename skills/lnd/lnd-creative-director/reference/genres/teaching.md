# Genre: teaching

**Grounding posture:** faithful (claims trace to the source or the approved knowledge sheet; wording may be the narrator's own).
**Arc (in order; * = required):** hook* -> promise* -> bridge -> build (1-4 sections)* -> check* -> apply -> payoff*
**Opens with:** a concrete situation, puzzle or misconception the viewer recognises. Never a definition, never an agenda slide.
**Good:** one running example the whole lesson returns to; ideas named after they are seen; a real check the viewer can pass; the ending returns to the opening situation, now solved.
**Bad:** a tour of the source in its own order; three examples that each appear once; a quiz on trivia; "in this video we will".
**Never:** statistics without a source, learning-styles claims, invented quotes presented as real.
**Visual kinds that fit:** a person in a situation, a value that visibly changes, a process running, the rule large with its one exception, a before and after.
